# Sources and provenance

## Primary NASA background
- [NASA Small Spacecraft Technology State of the Art](https://www.nasa.gov/smallsat-institute/sst-soa/) — subsystem design background and concepts.
- [NASA Space Apps Challenge 2026](https://www.spaceappschallenge.org/2026/challenges/) — challenge statement and official resources.
- [NASA Earth Science](https://science.nasa.gov/earth/) — motivation for Earth-observation missions.

## Model provenance
- Circular orbital period derives from two-body Keplerian dynamics, using standard Earth gravitational parameter.
- Ideal eclipse estimate derives from circular geometry with solar beta angle zero.
- **No numerical component parameter currently originates from a NASA hardware datasheet.** All initial catalog entries use `isSynthetic: true`.
- Game credits are invented points, not USD cost estimates.
- Communication windows and science mission targets are gamified assumptions.

## Contribution and disclosure
The source code is AI-assisted. Human contributors must independently validate physics, software tests, and source attributions. Keep a record of AI tools used in the final submission.
