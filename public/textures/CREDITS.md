# Local texture provenance

Downloaded 2026-11-14 (America/Bogota). Unmodified JPEGs. No runtime third-party requests.

- earth-blue-marble.jpg: 2048×1024, NASA Blue Marble 2002. NASA Goddard Space Flight Center; image Reto Stöckli, enhancements Robert Simmon, MODIS and credited supporting datasets. Historical composite, not current weather. Source: https://science.nasa.gov/earth/earth-observatory/the-blue-marble-true-color-global-imagery-at-1km-resolution/
  Download: https://assets.science.nasa.gov/content/dam/science/esd/eo/content-feature/bluemarble/images/land_ocean_ice_cloud_2048.jpg
- moon-lroc.jpg: 2048×1024, CGI Moon Kit 2025 color map, NASA Scientific Visualization Studio / Ernie Wright; LRO LROC WAC mosaic (Arizona State University), polar fill from LOLA. Aesthetic rendering map, not a scientific measurement product. Source: https://svs.gsfc.nasa.gov/4720/
  Download: https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_2k.jpg

NASA usage guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/ . Educational/informational use with attribution; no endorsement implied. These assets are credited separately from repository code. No NASA logo or insignia used. ISS, spacecraft and debris meshes are synthetic project geometry, not NASA CAD.

The briefing artwork uses `briefing-earth.jpg`, an orthographic projection of the local NASA Blue Marble image centered over the Americas with a stylized atmospheric rim. `briefing-starfield.png` is a procedural illustration.
